# 수학 SoftWare · 2026 수학·과학 축제

2026 수학·과학 축제 **‘수학 SoftWare’** 활동 안내 웹페이지입니다.
안내 캐릭터 **수리봇**이 각 페이지에서 활동을 소개하며, 활동 목록은 **게시된 구글 시트(CSV)** 에서 실시간으로 불러옵니다.

## 페이지 구성
| 주소 | 내용 |
|---|---|
| `#/` | 홈 (축제 표지, 수리봇 인사, 활동 개수) |
| `#/intro` | 수학 SoftWare 소개 · 목표 |
| `#/activities` | 활동 목록 (검색, 분류별 필터) |
| `#/activity/번호` | 활동 상세 (설명, 방법, 시작 버튼, QR 코드, 이전/다음) |
| `#/guide` | 참여 방법 |

## 구글 시트 작성 방법
시트 **첫 줄(머리글)** 의 이름을 보고 자동으로 열을 인식합니다. 필요한 열만 쓰면 됩니다.

| 머리글 예시 | 용도 |
|---|---|
| 번호 / 순번 | 카드 번호, 정렬 순서 |
| 활동명 / 제목 / 이름 | **활동 이름 (필수)** |
| 설명 / 내용 / 소개 | 활동 설명 |
| 활동 방법 / 방법 | 상세 페이지의 ‘활동 방법’ |
| 링크 / URL / 주소 | ‘활동 시작하기’ 버튼과 QR 코드 |
| 이미지 / 썸네일 | 카드 이미지 (구글 드라이브 공유 링크도 가능) |
| 분류 / 구분 / 영역 | 분류 필터 |
| 대상 / 학년 / 난이도 | 태그 |
| 안내 / 대사 / 멘트 | 상세 페이지에서 수리봇이 하는 말 |
| 아이콘 / 이모지 | 이미지가 없을 때 카드 아이콘 |
| 공개 / 표시 | `X`, `N`, `비공개` 등이면 숨김 |

그 밖의 열은 상세 페이지 ‘활동 정보’에 그대로 표시되고, URL 값은 ‘관련 링크’ 버튼으로 표시됩니다.
시트를 수정하면 페이지를 새로고침할 때 바로 반영됩니다(구글 게시 캐시로 최대 몇 분 걸릴 수 있음).

## 설정 변경
`js/config.js` 에서 시트 주소, 제목, 소개 목표, 참여 방법 단계를 바꿀 수 있습니다.

## GitHub Pages로 공개하기
1. 저장소 **Settings → Pages** 로 이동
2. **Source: Deploy from a branch**, Branch: `main` / `(root)` 선택 후 Save
3. 잠시 후 `https://kochiworks.github.io/mathsw2026/` 에서 접속

## 파일 구조
```
index.html        페이지 뼈대
css/style.css     가을 축제 테마 스타일
js/config.js      사이트 설정 (시트 주소 등)
js/app.js         시트 불러오기 · 화면 구성
assets/           수리봇 캐릭터 이미지
```

# 수학 SoftWare · 2026 수학·과학 축제

2026 수학·과학 축제 **‘수학 SoftWare’** 활동 안내 웹페이지입니다.
안내 캐릭터 **수리봇**이 각 페이지에서 활동을 소개하며, 활동 목록은 저장소의 엑셀 DB 파일 **`data/mathsw_db.xlsx`** 의 `DB` 시트를 직접 읽어 옵니다.

## 페이지 구성
| 주소 | 내용 |
|---|---|
| `#/` | 홈 (축제 표지, 수리봇 인사, 활동 개수) |
| `#/intro` | 수학 SoftWare 소개 · 목표 |
| `#/activities` | 활동 목록 (검색, 분류별 필터) |
| `#/activity/번호` | 활동 상세 (설명, 방법, 시작 버튼, QR 코드, 이전/다음) |
| `#/guide` | 참여 방법 |

## 활동 목록(DB) 수정 방법
엑셀 파일만 바꾸면 됩니다. 코드는 고칠 필요가 없습니다.

1. 내 컴퓨터에서 `mathsw_db.xlsx` 의 `DB` 시트를 수정합니다. (활동 추가·삭제, 링크 변경 등)
2. GitHub 저장소의 **`data`** 폴더 → **Add file → Upload files** 로 같은 이름(`mathsw_db.xlsx`)의 파일을 올리고 **Commit changes** 를 누릅니다.
3. 1~2분 뒤 사이트를 새로고침하면 반영됩니다.

> 파일 이름은 반드시 `mathsw_db.xlsx`, 시트 이름은 `DB` 를 유지해 주세요. (바꾸려면 `js/config.js` 의 `dataFile`, `sheetName` 수정)
> 저장소가 공개되어 있으므로 엑셀 파일에 학생 개인정보를 넣지 마세요.

### 인식하는 머리글
| 머리글 예시 | 용도 |
|---|---|
| 연번 / 번호 | 카드 번호, 정렬 순서 |
| 활동 / 활동명 / 제목 | **활동 이름 (필수)** |
| 설명 / 내용 / 소개 | 활동 설명 |
| 활동 방법 / 방법 | 상세 페이지의 ‘활동 방법’ |
| 링크 / URL / 주소 | ‘활동 시작하기’ 버튼과 QR 코드 |
| 이미지 / 썸네일 | 카드 이미지 |
| 분류 / 구분 / 영역 | 분류 필터 |
| 난이도 / 대상 / 학년 | 태그 |
| 안내 / 대사 / 멘트 | 상세 페이지에서 수리봇이 하는 말 |
| 아이콘 / 이모지 | 카드 아이콘 (이모지 또는 `assets/icons/파일.png` 같은 이미지 경로) |
| 공개 / 표시 | `X`, `N`, `비공개` 등이면 숨김 |

그 밖의 열은 상세 페이지 ‘활동 정보’에 그대로 표시되고, URL 값은 ‘관련 링크’ 버튼으로 표시됩니다.

## 설정 변경
`js/config.js` 에서 제목, 소개 목표, 참여 방법 단계, 활동별 아이콘 이미지(`activityIcons`)를 바꿀 수 있습니다.

## GitHub Pages로 공개하기
1. 저장소 **Settings → Pages** 로 이동
2. **Source: Deploy from a branch**, Branch: `main` / `(root)` 선택 후 Save
3. 잠시 후 `https://kochiworks.github.io/mathsw2026/` 에서 접속

## 파일 구조
```
index.html        페이지 뼈대
css/style.css     가을 축제 테마 스타일
js/config.js      사이트 설정 (문구, 아이콘 등)
js/xlsx-reader.js 엑셀 파일 읽기
js/app.js         화면 구성
data/mathsw_db.xlsx  활동 DB 엑셀 (이 파일을 고치면 사이트에 반영)
assets/           수리봇 캐릭터 이미지
```
